Privacy policy

Zyntrivo Shorts Automation is a personal tool running on its owner's PC. This policy describes the installed tool and this information website.

Google data the tool uses

With the owner's authorization, the tool uses the YouTube channel ID and name to verify the selected destination. It submits video files, titles, descriptions, licence credits, audience declarations and publishing visibility to YouTube. It reads metadata for relevant uploaded videos when checking ownership or resolving interrupted uploads. OAuth access and refresh tokens permit these operations.

Purpose and limits

Google API data is used only to provide the authorized channel automation, in accordance with the Google API Services User Data Policy and its Limited Use requirements. The tool does not sell Google user data, use it for advertising or send Google credentials to a writing or speech model. Local models receive story text and recent local scripts to produce new fiction and narration.

Storage and retention

OAuth credentials, channel approval, generated stories, editorial reviews, videos, captions, licence records, upload receipts, operational logs and duplicate history are stored on the owner's PC. Tokens are refreshed locally when Google permits it. Logs avoid raw credential-bearing errors. Successfully uploaded public autonomous media is removed locally after the configured retention period, initially 30 days. Scripts, captions, rights, reviews, receipts and upload history remain for quality checks and duplicate avoidance. The initial reviewed collection and held private test are retained. The owner can remove local data when it is no longer needed.

Sharing

Completed videos and their publishing metadata are sent to Google/YouTube as instructed by the owner. Public videos and descriptions are visible on YouTube. No other person or paid AI service receives OAuth tokens or private channel data through this workflow. Third-party local software and public model/asset downloads are obtained during setup. This website contains no account-data collection form, analytics script or advertising tracker.

Website hosting

This website is intended for GitHub Pages hosting. GitHub records visitors' IP addresses for security purposes. Its handling of hosting data is described in the GitHub Privacy Statement.

Control and revocation

The owner can stop scheduled uploads, disable uploading in the local configuration, or revoke the tool's Google account access in Google account connections. Revocation prevents further authorized API access. Removing the locally stored token and channel approval ends local authorization. Uploaded content is managed separately in YouTube Studio.

Contact

Contact the owner at zyntrivo1@gmail.com. Do not send credentials or authorization codes in email or public issue reports.
